## P0 定义（先读这一节）

**P0 = 当天工作做不下去。**

一句话判定：**问「今天这顿饭还做得出来吗 / 今天这个单还下得出去吗？」——做不出来 = P0；能做出来但别扭 = 不是 P0。**

P0 当场找 Terry，当天修；不是 P0 的照常记进表里，**本周不改**。

### 是 P0（正例）

1. 帮厨打开 `#/prep`，今天那一天是空的 / 显示「数据未就绪」 → **今天切什么不知道**，备料停摆。
2. 采购单里某个食材整行不见了，或者落进了「待补全」，采购员今天下不了单 → **明天缺料，明天的菜做不出来**。
3. 厨房那台手机扫码打不开、白屏，而且没有离线副本 → **帮厨今天拿不到单**。
4. 备料单上番茄写成 `3 кг`（实际要 30 кг）——数量错到会做不出来这一餐。

### 不是 P0（反例）

1. 「字太小」「颜色不好看」「调料要划两下才看到」——难用，但**今天照样切完了**。
2. 「『滚刀块』这个译名怪」——帮厨看懂了也切了，只是词不地道。→ 记原话，复盘周回投词表。
3. 「采购单上没有菜贩电话，我自己微信里有」——**绕过去了**，当天没耽误。
4. 「我想要一个『做完了』的勾选」——这是新功能，第一轮明确不做（`plan-for-terry.md` §7），进第二轮清单。
5. 「预估价跟实际差了 8%」——单还是下出去了，菜也做出来了。

### 最容易记错的一条

> **「不好用」不是 P0。「做不下去」才是。**

一个人说「这个太麻烦了」的时候，接着问一句：「那今天的活你干完了吗？」
- 干完了 → 不是 P0，照记，**不要**今天改代码。
- 没干完 / 得靠别人替他干 → 是 P0。

## 每天怎么填

- **日期**：`2026-10-XX`。
- **角色**：帮厨 / 采购员 / 师傅 / 顾客。
- **原话**：逐字。原话是乌克兰语就写乌克兰语，后面括号里补一句中文大意。
- **是否阻塞**：只填 `P0` 或 `否`。拿不准的按上面那条最容易记错的判。
- **结论 / 动作**：只能是这五种之一——`改数据` / `改渲染` / `改页面` / `不改 + 理由` / `进第二轮清单`。P0 的行还要写「当天怎么处理的」。

每天最后补三行收尾。汇总后开 issue 或在 PR 描述里直接引用本文件的行。
