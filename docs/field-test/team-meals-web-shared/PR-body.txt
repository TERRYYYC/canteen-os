## 改了什么

C1 introduces shared conditional requests and editing state for the team-meals flow. New plan/dish/list writes require a creation lock or the current blob lock. TeamMealsApi reads v2/v3 and ShoppingList sources at an explicit revision, fetches authenticated image bytes from the same revision, and isolates private caches by auth lifetime. The legacy numeric API keeps its strict types and rejects unsupported new formats instead of inventing portions or quantities.

The editor retains each document's draft and unresolved operation across language redraws and navigation. Returning to an unknown save result cannot issue another write until current-then-pinned reads establish its outcome. Logout clears credentials before notifying observers, and successful writes invalidate both new and legacy facade caches at the same Worker endpoint.
