3. **调度/Q 的最终验收**：用隔离测试仓库与专用凭据完成保存→读取→发布→同版清单/详情，真实条件写冲突、旧客户端降级防护、回退/清单进度及资产来源；保留各层输入 revision、实现 commit 和原始响应。无此环境时保持 L2 未执行，不能把 mock ACK 当真实同步。
4. **产品/设计与实际使用者**：完成三语两尺寸主流程及不完整/冲突/旧版状态签收，实际排菜并辨认需买材料；确认真实配方是否漏录。资料完整性、库存准确性、永久归档、顾客订单不由本索引宣称。
