# 菜谱知识库原生页面

本页承接用户授权的 SQLite 知识库接回工作，以既有后台 token、颜色、字号和原生 DOM 实现。管理首页第一入口为「菜谱知识库」；旧菜品/食材编辑页显示「发布历史资料，修改不会自动同步到新知识库」。旧菜单、备料、采购的版本选择不变。

## 页面与交互

- `#/admin/knowledge`：标题、使用边界说明、搜索词与标签、搜索按钮、新建按钮；逐卡显示名称、说明、标签、版本与更新日期（身份 ID 仅保留在折叠资料标识内），使用「继续加载」分页。空库、无结果、加载中、连接失败各有明确状态。相同名称的卡片不合并。
- `#/admin/knowledge/new`、`#/admin/knowledge/:uuid`：返回列表、名称/版本，五组卡片：基本资料、食材调料、步骤、素材、来源；底部保存栏。每个多语字段并列中/英/乌输入，手机折为单列；其他语言不会因切换界面语言被清空。
- 食材：名称、角色、未知/精确/适量/原文四种数量、原始文字、预处理；数量用文本保留精度；配料与步骤可上下移动和移除。删除有关联的步骤时素材转为参考。
- 素材：外部图片/视频 URL、图片文件上传、封面/参考/步骤用途、开始/结束秒数；图片预览通过鉴权网关取得 blob。来源：标题、作者、文字/网址；新增、移除引用。已经存在的来源/素材记录只读，引用可以调整。
- 历史与导入证据是只读可展开区域；历史显示完整当时内容、来源和素材。导入原文单独展示，普通保存不回写证据。
- 失败保留输入；冲突可先看历史，手动确认放弃输入后重新读取；网络不确定时锁定编辑并用相同幂等键核对。路由/语言切换在同一会话内保留草稿，整个页面刷新提示未保存；换令牌清理旧会话资料。

## 视觉与无障碍

沿用 `backoffice-v1.html` token：表面卡片、橙色主按钮、灰色次要信息。最大内容宽度 1040px；双列基础项、三列语言项，窄屏一列。标签显式关联表单；异步状态 `role=status`，错误 `role=alert`；所有操作可键盘完成。新的 CSS 只作用 `.kb`。

## 验收

新建同名两款、三语保留、未知量不转零、精确小数保留字符串、配料/步骤稳定 ID、保存 If-Match、冲突不丢输入、历史只读、未知保存同键重试、503 明示、鉴权 blob 回收。动态加载本模块不增加菜单入口首屏主体。

## 实现验证（2026-09-19）

- `pnpm -C packages/web typecheck`、`pnpm -C packages/web build` 通过。知识库为独立动态 JS 包，gzip 12.76 KB；主入口 gzip 17.20 KB。
- `pnpm -C packages/web test`：629 项通过；其中 `knowledge-library.test.mjs` 15 项直接执行真实 DOM renderer 与 API，涵盖列表分页、三语/未知量、幂等重放、冲突、鉴权图片、原文证据、离屏完成与跨语言历史失效。这是 DOM harness 回归，不代替真实浏览器视觉验证。
- 首页测试确认新增第八入口链接；旧菜单导入测试固定自身 fixture 时钟为 2026-09-13，原 HEAD 与当前代码在此时钟下均 30 项通过；业务日期校验未变。
- 本地单独构建尚未生成发布 data，PWA 的 data glob 提示为空；部署组合构建需先生成真实发布资料。
